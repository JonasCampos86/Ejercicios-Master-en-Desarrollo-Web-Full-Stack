Juego de las parejas

¡Encuentra todas las parejas de colores! Elige el número de filas y columnas: el total de casillas debe ser par. Pulsa dos casillas para descubrir sus colores. Si coinciden, quedarán descubiertas; si no, volverán a ocultarse. El cronómetro comenzará al seleccionar la primera casilla y se detendrá cuando completes todas las parejas.

En móvil, las casillas se distribuyen según el espacio disponible, manteniendo el total elegido.

Tu progreso se guarda automáticamente. Al volver o recargar la página, recuperarás las parejas acertadas y el tiempo acumulado. El cronómetro continuará cuando pulses una casilla cerrada. Para empezar de nuevo, pulsa «Nueva partida».
